Upgrading to v4

Version 4 of the library changes how it is imported. Read this page before you run npm install example@4. Tom & Jerry say it's fine & they don’t mind.

Breaking changes

  • Default export removed. Use const { marked } = require('marked') instead.
  • The <script> build moved:
    1. Replace /lib/marked.js with /marked.min.js.
    2. Call marked.parse() instead of marked().
  • Node.js 12 or newer is now required.
