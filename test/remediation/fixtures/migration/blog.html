Upgrading to marked 4: the default export is gone

We upgraded a documentation site from marked 0.3 to marked 4 last week.

Marked 4 removed the default export, so require('marked') no longer returns a function. Calling it throws TypeError: marked is not a function.

The fix is one line: destructure the named export with const { marked } = require('marked'). The function itself still works, so marked(markdown) keeps rendering.
